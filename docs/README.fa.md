# ماژول آفلاین خلاصه‌سازی متن عربی — خلاصهٔ فارسی

این مخزن فاز نخست (MVP) یک خلاصه‌ساز انتزاعی عربی است. ورودی آن متن خبری یا گزارش سازمانی ۳۰۰ تا ۱۰۰۰ کلمه‌ای است و خروجی، خلاصه‌ای ۱۰ تا ۳۰ درصدی (۳۰ تا ۳۰۰ کلمه) است. سامانه کاملاً آفلاین و روی CPU اجرا می‌شود. راهنمای کامل انگلیسی در `README.md`، معماری در `docs/architecture.md` و همهٔ تصمیم‌ها در `PROGRESS.md` آمده است.

## مراحل (نوت‌بوک‌های Colab)

۱. **‏`01_data`** (CPU): دریافت XL-Sum عربی با نسخه و هش ثابت، حذف تکراری‌ها، ساخت مجموعه معیار ۲۴۰ متنی (۱۲۰ خبر + ۱۲۰ گزارش سازمانی)، بررسی نشت داده و ورود پیش‌نویس خلاصه‌های مرجع.
۲. **‏`02_preprocess`** (T4): کالیبراسیون توکنایزر، قطعه‌بندی و اجرای آزمایشی خط لوله.
۳. **‏`03_finetune`** (T4): فیلتر وفاداری داده‌های آموزشی، جست‌وجوی نرخ یادگیری AraBART (‏1e-5، 3e-5، 5e-5؛ حداکثر ۵ دوره؛ دستهٔ مؤثر ۱۶؛ توقف زودهنگام با patience=2؛ بذر ۴۲)، یک اجرای مقایسه‌ای AraT5v2، تنظیم پارامترهای تولید روی مجموعه اعتبارسنجی، و ذخیرهٔ مدل همراه با شناسنامه (هش فایل‌ها) و دفتر ساعت GPU.
۴. **‏`04_optimize`** (CPU): مقایسهٔ PyTorch و ONNX Runtime در دو حالت FP32 و INT8. ابتدا شرط‌های الزامی بررسی می‌شوند: حجم مدل ≤ ۱ گیگابایت، حافظه ≤ ۸ گیگابایت، میانهٔ زمان ≤ ۱۵ ثانیه و افت ROUGE-1 ≤ ۰٫۰۲. سپس امتیاز ترکیبی ۵۰/۳۰/۱۰/۱۰ محاسبه می‌شود.
۵. **‏`05_evaluate`** (T4): اجرای همهٔ سامانه‌ها روی مجموعه معیار؛ محاسبهٔ ROUGE-1/2/L با بازهٔ اطمینان، بررسی طول، کنترل خودکار اعداد و نام‌ها، زمان پاسخ و BERTScore؛ ساخت برگه‌های ارزیابی انسانی کور (۱۰۰ خروجی، دو ارزیاب، Weighted Cohen’s Kappa، ارزیاب سوم برای اختلاف بیش از یک امتیاز)؛ و گزارش نهایی معیارهای پذیرش.

همهٔ نوت‌بوک‌ها پس از قطع اتصال Colab از همان نقطه ادامه می‌یابند.

## نصب و اجرا روی سیستم آفلاین

سیستم مرجع: ‏x86-64 با دست‌کم ۸ هسته، ۱۶ گیگابایت RAM و Python 3.13. بسته‌ها را روی یک سیستم متصل با `pip download -r requirements/cpu-runtime.txt -d wheelhouse` دریافت کنید. سپس پوشهٔ مخزن، `wheelhouse` و پوشهٔ مدل `models/arabart_ft_cpu` را به سیستم آفلاین منتقل کرده و نصب کنید:

```bash
pip install --no-index --find-links wheelhouse -r requirements/cpu-runtime.txt
pip install --no-deps -e .
python -m arabic_summ summarize --model-dir models/arabart_ft_cpu --input article.txt   # خط فرمان
python -m arabic_summ serve --model-dir models/arabart_ft_cpu                          # رابط وب محلی
python bench/run_bench.py --model-dir models/arabart_ft_cpu --texts benchmark_items.csv  # آزمون پذیرش
```

رابط وب فقط روی `127.0.0.1` در دسترس است و هیچ فراخوانی شبکه‌ای انجام نمی‌دهد. هر خروجی، اعدادی از خلاصه را که در متن ورودی نیامده‌اند نشان می‌دهد.

## نکات مهم

* **خلاصه‌های مرجع**: به درخواست کاربر، هر ۲۴۰ خلاصهٔ مرجع ابتدا با مدل زبانی پیش‌نویس شده‌اند (`llm_draft`). هر کدام باید پیش از گزارش نهایی توسط یک فرد مسلط به عربی بازبینی و تأیید شود. نتایج باید با عنوان «پیش‌نویس مدل، تأییدشده توسط انسان» گزارش شوند. این مورد انحراف از بند ۱۱٫۱ پیشنهاده است و به تأیید راهبر پروژه نیاز دارد.
* **نتایج میانی**: روی پیش‌نویس‌های مرجع، روش‌های پایهٔ استخراجی به ROUGE-1 حدود ۰٫۳۵ تا ۰٫۳۷ می‌رسند. هدف پذیرش بیشتر از ۰٫۴۰ است.
* **مجوز**: داده‌های XL-Sum تحت CC BY-NC-SA 4.0 (غیرتجاری) منتشر شده‌اند و این محدودیت به مدل تنظیم‌شده هم منتقل می‌شود. مدل AraT5v2 فقط برای استفادهٔ پژوهشی است.
