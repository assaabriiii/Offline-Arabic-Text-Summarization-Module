# Offline Arabic Text Summarization Module

Phase 1 MVP: an offline abstractive summarizer for Modern Standard Arabic news and
organizational reports (300–1000 words → a 10–30% summary) that runs on a CPU.

- `src/arabic_summ/`: the importable package (all logic)
- `configs/default.yaml`: every setting
- `notebooks/`: thin Colab drivers, generated by `tools/build_notebooks.py`
- Notebooks in order: `01_data` → `02_preprocess` → `03_finetune` (T4 GPU) → `04_optimize` → `05_evaluate`
- `tests/`: fast CPU unit tests (`pip install -e ".[test]" && pytest`)
- `docs/reference_guideline.md`: how benchmark reference summaries are written and reviewed
- `PROGRESS.md`: status and decisions

The full install-and-run guide (English, plus a Persian summary) will be added with the MVP.
